# Style reference - Monster Guardians

## Voices
| Character | JP traits | English voice |
|---|---|---|
| Narrator (intro) | formal, mythic | Measured, storybook: "In a world without gods, there can be no prosperity." |
| {name} (hero/heroine) | rarely speaks | Plain, earnest. |
| Klimt (old man) | わし, じゃ, のう, おぬし, そなた | Grumpy, folksy old scholar: "What a racket!", "you", "my boy" sparingly; contractions; "Hmph". Never "thou". |
| Bellingham (duke) | ワシ, 君, だよ, ハハッ | Smug, theatrical aristocrat: "Do you understand?", "my dear", "Hah!" |
| Zago, Ramirez | broken speech with ・・・ | Dim brutes, short halting phrases: "More... fight!" |
| Winslow II (lord) | dignified | Noble, formal. |
| Guards / pursuers | rough | Coarse soldiers: "Don't let the kid escape!!" (the hero may be a girl: no he/him for {name}) |

## Approved pilot pairs (script/story.json 0CFF84-0D09D2)
- 神のいない世界に、繁栄などは無い / だから私が使わされた。
  -> In a world without gods, there can be no prosperity. / That is why I was sent.
- 男「このタクトを見て思い出さないのか？」
  -> Man: "Does this baton not stir your memory?"
- 追っ手２「えーと・・・こいつの名前は？」
  -> Pursuer 2: "Uh... what was this kid's name again?"
- 老人「やかましいのう！わしゃ寝起きは機嫌がわるいんじゃ！」
  -> Old Man: "What a racket! I'm always in a foul mood when I've just woken up!"
- クリムト「うーん、そなたはヴァンダム城のウィンスローの{word2:0001}とみたが・・城でなにかあったかの？」
  -> Klimt: "Hmm, I take it you are Winslow's {word2:0001}, of Vandam Castle... Did something happen at the castle?"
