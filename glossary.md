# Glossary - Monster Guardians (GBA)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (asked of the user 2026-10-13)
- Honorifics: dropped. Name order: Western (given-family).
- Romanisation source: official English where one exists (Konami material), else Hepburn.
- Credits: English. Specs/plans: pre-approved (keep going, report at end).
- Graphics text: all in scope (title subtitle, chapter cards, menus, labels).
- Abbreviations: none; full names and terms everywhere, prefer engine changes over shortening.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', ・・・ -> ..., ！？ -> ?!, ～ (place headers ～X～) -> keep as - X -.
- No suffix glued onto a variable ({name}'s is fine; no "1th").
